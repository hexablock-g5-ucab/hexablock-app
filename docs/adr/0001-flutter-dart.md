# ADR-0001 — Flutter + Dart 3 client

- Status: Proposed
- Date: 2026-11-13

## Context
The statement requires a language with generics and a mobile release.
## Decision
Flutter stable, Dart >= 3.6 (bounded generics, sealed classes, pub workspaces).
## Alternatives considered
React Native, Unity, Godot.
## Consequences
One language for engine and UI; engine stays pure Dart.
