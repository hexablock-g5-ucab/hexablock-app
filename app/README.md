# app

Create the Flutter project here on day one (it is not generated by the scaffold):

```bash
flutter create --org com.ucab.hexablock --project-name hexablock --platforms android,ios app
```

Then add to `app/pubspec.yaml`: `resolution: workspace`, `environment: sdk: ^3.6.0` and the path
dependencies `hexa_engine: {path: ../packages/hexa_engine}` (same for application and infrastructure),
`flutter_localizations` and `intl`.

Layout inside `app/lib/`:
```
composition_root.dart     wires factories, use cases and aspects (decorators)
presentation/             view models, screens (home, game selector, level selector, game, victory, defeat, settings)
presentation/board/       BoardPainter, input adapters (drag, swipe)
l10n/                     app_en.arb, app_es.arb
```
