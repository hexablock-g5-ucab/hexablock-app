# friday-review

1. Run the `reviewer` agent on the whole repository.
2. Update the compliance checklist (statement sections 3 to 9): done / in progress / missing.
3. List what will be demoed, the open questions for the professor and the risks for next week.
4. Write the result to `docs/reviews/YYYY-MM-DD.md`.
