# Pre-Implementation Checklist

- [ ] Read `AGENTS.md`, the UC file, `current_constraints.md`, `docs/HANDOFF.md`
- [ ] The UC is approved (status `Approved` in its header)
- [ ] Audited the relevant files and wrote the current state in plain language
- [ ] Listed files to touch and tests to write (one per flow and business rule)
- [ ] Confidence >= 95 % (or questions asked and answered)
- [ ] **Explicit human approval received**
