# Pre-Commit Checklist

- [ ] `git status` reviewed; only intended files staged
- [ ] No secrets, `.env`, build artifacts
- [ ] Message: `<type>(<scope>): <subject>` + `Refs:` (+ `AI-Assisted:` if applicable)
- [ ] **Human approved the commit.** Agents never commit or push by themselves.
